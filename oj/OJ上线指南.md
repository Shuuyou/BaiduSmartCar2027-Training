# OJ 上线指南（免费托管，无需服务器）

> 用途：为 M0 阶段热身题提供在线判题与排行榜体验。**仓库 `task0-warmup` 分支的 GitHub Actions 自动判题已可独立完成考核**，OJ 为可选增强（实时榜单、作业跟踪、比赛氛围）。
> 题目包：`oj/hydro-warmup/`（文件夹版）与 `oj/hydro-warmup.zip`（导入用），含参考测试数据，**请勿上传至学生可见的公开仓库**。

## 方案 A（推荐）：hydro.ac 官方免费托管域

hydro.ac 是 HydroOJ 官方托管站，注册用户可免费创建独立域（独立判题、独立权限组、零运维）。

上线步骤（约 30 分钟）：

1. 访问 https://hydro.ac 注册账号；
2. 登录后进入「我的 → 我的域 → 创建域」，填写域名（如 `hdu-smartcar`）与名称；
3. 进入自己的域，在「题库 → 导入/添加题目」处上传 `oj/hydro-warmup.zip`（Hydro 支持批量导入题目文件夹压缩包）；
4. 「用户管理」中通过邀请链接或用户名添加学生，设为普通用户权限组；
5. 「作业/比赛」中创建一次热身赛，设置起止时间，学生提交即出实时榜单。

注意事项：

- 首次导入后逐题检查测试数据是否完整（每题应有 `testdata/` 下成对的 `.in`/`.ans`）；
- 官方交流渠道：Hydro 用户 QQ 群 1085853538；
- 免费域有资源配额，热身赛规模（百人以下）完全够用。

## 方案 B（备选）：洛谷团队

若 hydro.ac 访问不稳，可在 https://www.luogu.com.cn 申请创建团队，在团队题库中手工录入五道题（题面即 `problem.md`，测试数据逐组上传）。录入耗时约 1 小时，优点是学生对洛谷界面更熟悉。

## 方案 C（远期）：自建部署

未来若获得实验室服务器（最低 1 核 2G，Debian/Ubuntu），可按官方文档自建完整版：
官方文档 https://hydro.js.org ；支持一键安装脚本与 Docker 部署，题库数据可直接复用本目录题目包。
