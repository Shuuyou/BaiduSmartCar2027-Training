# 培训与考核方案（仓库内简版）

完整版由负责人维护，此处为成员可见的核心规则。

## 总分构成（100 分 + 5）

| 项 | 权重 | 说明 |
|---|---|---|
| 自动分（流水线） | 70 | OJ 通过率 + Actions 自动校验 + 模型指标（mAP/准确率）+ Git 提交轨迹 |
| 现场验收 | 30 | 集中验收日：实跑演示 + 细节追问链 + 限时小变更/修预埋故障 |

- **"有效使用 AI"加分（+5）**：能说清用 AI 做了什么、怎么验证它是对的、哪一步放弃了它的建议。
- 过程证据加分：小步迭代提交、笔记含失败分析；扣分：一次性大提交、笔记只有结论。

## 里程碑与筛选

| 节点 | 时间 | 形式 |
|---|---|---|
| M0 验收 | 11 月中 | 自动分 + 集中验收日（半天） |
| M1 分流项目 | 1 月中 | 项目验收 + 20 分钟答辩，可申请一次延期（≤2 周） |
| M2 寒假整合 | 2 月底 | 小组现场演示 + 互评 |
| M3 校内比武 | 4 月 | 模拟赛 |

- M0 验收未通过者：温和劝退或转旁听（保留下一届入口）。
- 分层：正式队员（一队/二队）/ 预备队员 / 学员。

## 使用 AI 的正确姿势

- 可以让 AI 解释概念、生成代码、排查报错；
- 不可以：让它替你跑完全程而你讲不清楚；把 AI 给的命令不加验证地执行；
- 每个任务分支里都有"验收追问清单"，提前公开，照着自己练。
