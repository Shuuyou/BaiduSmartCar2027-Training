# 任务一 · 让一张图片被 AI 看懂

> M0 阶段核心任务 ｜ 周期 2–3 周 ｜ 零硬件，个人电脑完成
> 情境：你是百度创意组智能小车的感知工程师，第一步是让小车"看懂"一张农场照片。

## 任务要求

1. 在 Ubuntu（双系统或 WSL2 均可）中完成 PaddlePaddle 与 PaddleDetection 的安装；
2. 使用**官方预训练模型**对 `data/` 中的 **5 张指定图片**（img_1 – img_5，取自 Wikimedia Commons 免费版权图库，请勿增删）执行目标检测；
3. 将带检测框的可视化结果输出至 `output/`，命名为 `vis_1.jpg` … `vis_5.jpg`；
4. 将每张图检测到的目标类别与数量整理为 `results.json`，格式见 `results.example.json`；
5. 在 `notes.md` 中记录全过程：每个报错原文、当时的尝试、最终结果；
6. push 到自己的仓库，Actions 自动校验 `results.json` 格式、`output/` 图片数量与 `notes.md` 内容。

## 提交结构

```
├── data/            # 5 张输入图片
├── output/          # 5 张可视化结果 vis_1.jpg ... vis_5.jpg
├── results.json     # 结构化检测结果
├── notes.md         # 踩坑记录（必填）
└──(其余为你的代码与脚本)
```

## AI 使用规范

- 允许：用 AI 解释安装报错、比较安装方案、说明检测结果含义；
- 不允许：让 AI 直接生成完整工程后跑不通即弃，无任何排查动作；
- 卡住时的标准动作：阅读报错原文 → 检索报错关键行 → 将完整操作步骤与报错一并提供给 AI。
