# HDU 智能车百度创意组 · 2027 届自学路线仓库

面向新大二/大一的组别成员培养仓库。**学习方式：自学 + 里程碑验收**，本仓库是你的地图。

## 怎么用这个仓库

1. Fork 本仓库（或接受邀请加入组织）；
2. 按路线图推进，**每个学习任务对应一个分支**（`task*` 开头），切到对应分支看任务说明；
3. 所有学习记录、踩坑笔记、任务产出都提交在你自己的 fork 里——**提交轨迹本身就是考核证据**。

## 三条规矩

1. **鼓励使用 AI**（Coding Agent、大模型都可以），但你要能驾驭它：验收时会追问"这步为什么这么做、这个报错怎么发现的"。AI 给什么跑什么、讲不清自己交的是什么 = 不过。
2. **`notes.md` 记录每个报错原文和你的解决尝试**——这份文件比代码更能说明你的真实投入。
3. **允许延期一次（上限两周）**，但要提前说。过期不候。

详细规则（评分权重、验收标准、淘汰机制）见 `docs/培训考核方案.md`。
