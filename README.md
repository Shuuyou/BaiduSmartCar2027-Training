# 任务二：教小车认识农场的字

> 定位：M0 巩固任务 · 2 周 · 零硬件 · 任务一通过后解锁
> 智慧农场赛题里，小车要靠识别指示牌上的文字和数字完成任务（水滴数、订单号、住户编号）。
> 本任务：用 PaddleOCR 识别 10 张指示牌图片中的文本。

## 任务要求

1. 复用任务一的环境（不需要重装——这就是考核点之一：你的环境还在吗？）；
2. 安装 PaddleOCR，对 `data/` 里 **10 张图片**（自选含文字的图片，或等组织方发布）做文字识别；
3. 结果写入 `results.json`，格式见 `results.example.json`；
4. 至少完成 1 次**微调/后处理实验**：例如对低置信度结果做过滤、对中文结果做纠正规则，把实验前后对比写进 `notes.md`；
5. push 到 fork，Actions 自动校验。

## 验收追问清单

- PaddleOCR 的检测和识别是两个阶段，分别干什么？
- 你过滤低置信度结果的阈值怎么定的？依据是什么？
- 中文识别错字（比如"水滴"识别成"水滴了"）你会怎么修？
- 如果指示牌是斜着拍的（小车视角），识别率会怎样？有什么办法？

## 评分

自动分 60% + 验收日 40%（现场跑 + 追问 + 现场换 3 张新图测试鲁棒性）。

## 用 AI 的正确姿势（本任务）

- ✅ 让 AI 帮你设计后处理实验方案、解释 PP-OCRv4 结构
- ❌ 让 AI 替你写完整实验然后只贴个结论——notes.md 里要有实验前后的原始对比
- 本任务的重点是"实验素养"：改一个变量、记录一次结果，这和你以后调车一模一样。
