# 任务二 · 教小车认识农场的字

> M0 阶段巩固任务 ｜ 周期 2 周 ｜ 零硬件，个人电脑完成 ｜ 任务一通过后开放
> 情境：智慧农场赛题中，小车需识别指示牌上的文字与数字（水滴数、订单号、住户编号）以完成任务。
> 本任务：使用 PaddleOCR 识别 10 张图片中的文本，并完成一次后处理对比实验。

## 任务要求

1. 复用任务一的运行环境（环境可复用性本身是考核点）；
2. 安装 PaddleOCR，对 `data/` 中的 **10 张图片**（自选含文字图片，建议含指示牌类内容）执行文字识别；
3. 结果写入 `results.json`，格式见 `results.example.json`；
4. 完成至少一次**后处理实验**：例如低置信度过滤、常见误识替换规则，将实验前后的对比数据记录于 `notes.md`；
5. push 到自己的仓库，Actions 自动校验。

## AI 使用规范

- 允许：用 AI 设计后处理实验方案、解释模型结构；
- 不允许：仅提交结论而无实验前后原始数据——`notes.md` 需包含对比记录；
- 本任务考察实验素养：一次只改一个变量，记录一次结果。该方法与后续调参、调车完全一致。

## 验收追问清单（提前公开，供自查）

- PaddleOCR 的检测与识别两阶段各自的作用？
- 置信度过滤阈值如何确定？依据是什么？
- 中文误识（如多字、错字）时有哪些修复手段？
- 拍摄角度倾斜（小车视角）对识别率的影响及应对方法？

## 评分

自动分 60% + 集中验收 40%（现场运行 + 追问 + 以 3 张未见过的新图测试鲁棒性）。

## 进度规则

- 连续两周无提交记录且未说明原因者，视为退出本轮培养；
- 需要延期时提前申请（上限两周）。

任务通过后进入 M1 分流项目（届时在 `main` 分支公告）。
